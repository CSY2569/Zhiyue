# ReadApp 任务需求文档

> 文档版本：v2.2（2026-08-06）
>
> 本文档是 RBWA 的任务需求规格（Read Book With AI）。所有条目均为**产品需求**，不代表当前已实现状态；开发任务按本文档拆分与验收，逐条落地后勾选完成。
>
> **优先级定义**
> - **P0 核心**：产品成立必需，首发必须完成
> - **P1 重要**：主要体验场景必需，紧随其后
> - **P2 增强**：体验优化，排期宽松

## 1. 产品概述

### 1.1 产品定位
原生 AI 集成的本地阅读器：阅读 PDF（文字版 / 扫描版）与图片文件。选中文字即可翻译、解释、网页搜索；支持文本层标记（高亮 / 下划线 / 删除线 / 笔记）与图像层标记（画笔 / 便签 / 图章 / 形状）；内置本地 OCR（免费离线）与多模态 OCR（数学 / 外语）。

### 1.2 文档类型（贯穿全文）
| 类型 | 说明 | 文本层来源 |
|---|---|---|
| 文字版 PDF | 文档自带文本层 | pdfjs 原生文本层，无需 OCR |
| 扫描版 PDF | 无文本层（纯图像） | 需先本地 OCR 注入隐形文本层 |
| 图片文件 | PNG / JPG / WEBP 等 | 同扫描版处理 |

**核心原则**：两类文档在选中、标记、AI 能力上体验一致；区分仅在于文本层的获取方式。

### 1.3 产品原则
- **本地优先**：书籍、标注、进度、OCR 缓存全部本地存储，无服务端依赖
- **BYOK**：用户自带 API Key，兼容 OpenAI 兼容接口（OpenAI / DeepSeek / Kimi / 通义等）
- **双引擎 OCR**：中英文整页扫描免费离线；数学与外语走多模态大模型
- **标记与识别解耦**：图像层标记不依赖 OCR；文本层标记依赖文本层（原生或 OCR 注入）

## 5. 图像层标记（无需 OCR，两类文档均支持）

直接在页面 / 图像上叠加标记层，不依赖文字识别。

| 编号 | 优先级 | 需求 |
|---|---|---|
| 5.1 | P1 | **手写批注 / 画笔**：鼠标或触控笔直接绘制线条、圈注；本质为**矢量图形**（非位图涂抹），可选中、移动、删除，可调颜色 / 粗细 |
| 5.2 | P1 | **便签 / 文本框**：页面任意位置插入浮动注释框；内容独立存储，可编辑、可换行，与所选文字无绑定 |
| 5.3 | P1 | **图章 / 签名**：以图像形式盖在页面上（印章 PNG、手写签名图）；可缩放、旋转、移动 |
| 5.4 | P1 | **形状标注**：箭头、矩形、椭圆等几何图形；可调颜色、线宽、填充 |
| 5.5 | P1 | **图层模型**：标记与图像分离存储（不修改原图）；每个标记记录类型、归一化位置、样式；支持按类型筛选显示 / 隐藏、单独删除、整体清空 |
| 5.6 | P2 | **拼合导出**：导出时可选择是否将矢量标记渲染拼合进图像副本（输出带批注的新图片）；不拼合则导出标记数据（JSON） |

## 7. OCR（双引擎）

### 7.1 本地整页扫描（免费、离线，中 / 英文，**精准优先**）
> 已实现（2026-08）：7.1.1–7.1.6、7.1.8、7.1.9 —— rapidocr-core 引擎（PP-OCRv4 det/cls/rec，ONNX Runtime 静态链接，完全离线），`scripts/download_ocr_models.sh` 从 ModelScope 下载模型（sha256 校验）；实测 release 性能：快速 ~0.4s/页、高精度 ~1.8s/页（A4 合成页）。
| 编号 | 优先级 | 需求 |
|---|---|---|
| 7.1.1 | P0 | 模型：PP-OCRv4（det / cls / rec + 字符表）；提供下载脚本（含完整性校验）；模型缺失时应用内明确提示 |
| 7.1.2 | P0 | **扫描页自动检测**：无文本层的页面自动识别并提示，提供一键"扫描识别"；工具栏提供整页扫描入口 |
| 7.1.3 | P0 | 识别结果按行注入为**隐形文本层**（透明、可选中、与图像对齐），扫描页获得与文字版一致的选中 / 标记 / AI 体验 |
| 7.1.4 | P0 | **缓存**：按 (bookId, page) 缓存结果（持久化 + 内存），重复扫描 / 翻回秒开 |
| 7.1.5 | P0 | 引擎**懒加载**：首次扫描才加载模型，不扫描不占用内存；推理在后台线程执行，不阻塞 UI |
| 7.1.6 | P1 | 识别置信度展示：低置信度行可标记 / 提示用户复核 |
| 7.1.7 | P2 | 识别结果可手动修正（编辑行文本并回存） |
| 7.1.8 | P0 | **高分辨率识别**：扫描识别使用页面**原始分辨率**图像（短边不低于 1280px），不得使用屏幕显示分辨率截图，保证小字号 / 密集文本可识别 |
| 7.1.9 | P0 | **高精度模型**：默认使用高精度识别模型（PP-OCRv4 server 版 det/rec，准确率优先）；设置中可切换"快速模式"（mobile 模型）以换取速度与更小体积 |
| 7.1.10 | P1 | **图像预处理增强**：识别前自适应增强（灰度化 / 对比度 / 锐化 / 去噪），改善低质量扫描件的识别率 |
| 7.1.11 | P1 | **倾斜与四边形文本框**：文本框支持四点四边形（非轴对齐矩形），旋转矫正后送入识别，提升倾斜扫描页的检测与识别精度 |
| 7.1.12 | P1 | **多向文本矫正**：180° 方向分类 + 90° 旋转检测与矫正，支持横竖排混合版面 |

### 7.2 多模态区域 OCR（数学 / 外语）
| 7.2.1 | P0 | 工具栏"区域 OCR"：框选任意区域 → 多模态模型识别 / 分析（走视觉独立配置） |
| 7.2.2 | P0 | 数学公式与外语区域明确引导使用区域 OCR（页面提示） |
| 7.2.3 | P1 | 区域 OCR 结果与区域哈希缓存去重 |

### 7.3 图片文件阅读器
| 7.3.1 | P0 | 图片以阅读器形式打开：缩放（按钮 / Ctrl+滚轮）、OCR 扫描、标记、区域 OCR、标注全流程可用 |

## 10. 非功能需求
